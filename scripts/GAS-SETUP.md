# Chatwork メッセージ収集 GAS セットアップ手順

## 概要

Chatwork APIを30分おきに定期実行し、対象ルームのメッセージをGoogleスプレッドシートに自動蓄積するスクリプト。

## セットアップ（5分）

### 1. スプレッドシートを作成

Google スプレッドシートを新規作成する。名前は「Chatwork メッセージ収集」等。

### 2. Apps Script を開く

メニュー → 拡張機能 → Apps Script

### 3. コードを貼り付け

`gas-chatwork-collector.js` の内容をすべてコピーして、
Apps Script エディタの `コード.gs` に貼り付け（既存コードは全削除してから）。

### 4. スクリプトプロパティを設定

Apps Script の左メニュー → ⚙ プロジェクトの設定 → スクリプト プロパティ

| プロパティ | 値 | 例 |
|-----------|----|----|
| `CHATWORK_API_TOKEN` | Chatwork の API トークン | `ba3da8ee...` |
| `ROOM_IDS` | 取得対象のルームID（カンマ区切り） | `425737026,123456789` |

> 💡 ROOM_IDS はスクリプトプロパティの代わりに「設定」シートでも管理可能。

### 5. 初回セットアップ

1. 関数セレクタで `setup` を選択 → ▶ 実行
2. 権限の承認を求められたら「許可」
3. 「メッセージ」「ログ」「設定」の3シートが作成される

### 6. 接続テスト

1. 関数セレクタで `testConnection` を選択 → ▶ 実行
2. アカウント名とルーム情報が表示されればOK

### 7. 手動実行で動作確認

1. 関数セレクタで `collectMessages` を選択 → ▶ 実行
2. 「メッセージ」シートにデータが追加されることを確認

### 8. トリガー登録

1. 関数セレクタで `setupTrigger` を選択 → ▶ 実行
2. 30分おきに自動収集が開始される

## 運用後の操作

スプレッドシートを開くと上部に「🤖 Chatwork収集」メニューが表示される:

- **▶ 今すぐ収集**: 手動で即座に収集実行
- **🔗 接続テスト**: API接続の確認
- **⏰ トリガー登録**: 30分おき自動実行の開始
- **🛑 トリガー削除**: 自動実行の停止

## シート構成

### メッセージシート

| カラム | 内容 |
|--------|------|
| message_id | メッセージの一意ID（重複防止キー） |
| room_id | ルームID |
| room_name | ルーム名 |
| account_id | 発言者ID |
| account_name | 発言者名 |
| body | メッセージ本文 |
| send_time | 送信日時 |
| send_time_str | 送信日時（文字列） |
| update_time | 編集日時 |
| collected_at | 収集日時 |

### 設定シート

ルームIDを追加・削除するだけで対象ルームを管理可能。
`active` 列を `FALSE` にするとそのルームはスキップされる。

## 注意事項

- **フリープランは40日以前のメッセージ取得不可**（ビジネスプラン以上は無制限）
- **1回の取得で最大100件**（30分間隔なら通常取りこぼしなし）
- **レートリミット**: 5分間に300リクエストまで（通常運用では問題なし）
- APIトークンは発行者のアカウントに紐づく。そのアカウントが参加しているルームのみ取得可能。
